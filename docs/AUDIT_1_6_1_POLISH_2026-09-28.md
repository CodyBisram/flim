# FLIM 1.6.1 audit: bugs, races, performance, polish, features

Audited: origin/main at 8985ca3 (1.6.0 in App Store review). Read-only. Seven parallel reviewers
(feed/Spotlight races, capture/auth, performance and caching, Supabase backend, flows and copy,
visual system and icons, product), each told to skip anything already in `docs/reviews/OPEN.md`.
The lead re-read the highest-severity findings in the code (marked **[confirmed]**). Nothing was
built or run on a device; file:line references are at 8985ca3.

The "N shots from N friends" bug: fixed on main by removing the header count (8367b08). There is
no `feed_unseen_ids()`. `feed_unseen_count()` now only drives the Feed tab dot (see A-10).

## E. Visual system, icons and motion ("fresh and polished")

1. **App icon (P1).** One universal 1024 PNG: no dark or tinted variants, no `.icon`. The artwork (dark ground, cream frame, lens ring with highlight, amber strip) splits cleanly into layers.
   - Build `AppIcon.icon` in Icon Composer: ground as the background layer, then frame, lens (highlight as specular), and strip.
   - Keep the appiconset as the iOS 18 fallback, with added dark (transparent ground) and tinted (grayscale foreground, lens and strip brightest) variants.
   - Check all four iOS 26 modes and the iOS 27 clarity range.
2. **One brand mark.** Export the icon's polaroid-plus-lens as a custom SF Symbol (regular and ultraLight). Replace `camera.aperture` with it on the Splash (`SplashView.swift:11`), the empty states (`DarkroomView:1340`, `CameraView:795`, `RollsView:991`) and the widgets. The splash then matches the icon the person just tapped. This is the single biggest "fresh icons" win.
3. **Tab symbols.** `camera.aperture` has no `.fill`, so the Camera tab likely reads thinner than the other three. Use `camera`, `photo.stack`, `film.stack`, and `person.2` (or `rectangle.stack`) instead of `house`. Use base names only, and let the system fill the selected tab.
4. **One symbol per action.**

   | Action | Symbol |

   | Find friends | `person.2.badge.plus` |

   | Email | `envelope` |

5. **Error vs warning.** Errors use `exclamationmark.circle.fill`; the triangle is kept for real warnings. About 14 sites to switch.
6. **Animated toggles.** Only one site uses `.contentTransition(.symbolEffect(.replace))`. Add it to:
